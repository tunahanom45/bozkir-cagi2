# Bozkır Çağı — Oyun Güncellemeleri

Bu depo sadece **Bozkır Çağı** oyununun güncelleme paketlerini içerir.
Oyun (`BozkirCagi.exe`) her açılışta `surum.json` dosyasına bakar ve yeni sürüm varsa
`oyun_X.Y.Z.pck` paketini indirip kendini günceller.

Değişiklikler için: [DEGISIKLIKLER.md](DEGISIKLIKLER.md)
